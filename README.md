Una solución web moderna para la gestión de reservas y administración de agenda, diseñada especialmente para centros de belleza y spa con múltiples profesionales y servicios.

## 🌐 Descripción General

Esta plataforma permite a los usuarios reservar citas de manera rápida, recibir notificaciones automáticas y visualizar la disponibilidad del equipo en tiempo real. Además, proporciona a la administración un panel centralizado con herramientas para organizar servicios, profesionales, horarios y clientes de forma eficiente y segura.

## 🎯 Objetivo del Proyecto

Implementar una solución digital que:

- Optimice la gestión de reservas sin depender de redes sociales o mensajería instantánea.
- Reduzca la pérdida de oportunidades por falta de organización.
- Mejore la experiencia del cliente mediante recordatorios automáticos y reservas simplificadas.
- Sea escalable y adaptable a las necesidades futuras del negocio.

## ✨ Funcionalidades Clave

- 📅 **Agenda dinámica** por profesional y servicio.
- ✅ **Reservas online**, con confirmación automática por correo electrónico.
- 🔐 **Inicio de sesión seguro** mediante verificación por correo.
- 📬 **Notificaciones automáticas** para confirmar y recordar citas.
- 📱 **Interfaz responsive**, compatible con smartphones, tablets y computadores.
- 🧠 **Validaciones de datos en tiempo real** para evitar errores.
- 🧑‍💼 **Panel administrativo** para gestionar fácilmente horarios, clientes y servicios.

## 🧩 Tecnologías Utilizadas

### Frontend
- **Vue.js 3**
- **Vue Router**
- **Tailwind CSS**
- **Vuetify**
- **Pinia**

### Backend
- **Node.js + Express.js**
- **MongoDB**
- Arquitectura **MVC**
- **REST API**
- Autenticación segura con protección de rutas
- Despliegue mediante **Vercel**

## 💼 Beneficios Esperados

- Organización centralizada y profesional del flujo de atención.
- Disminución de ausencias y sobreagendamientos.
- Ahorro de tiempo en coordinación manual de citas.
- Plataforma moderna que potencia la fidelización de clientes.
- Preparada para integrar futuras mejoras como pagos en línea y promociones.

## 🚧 Estado del Proyecto

En desarrollo activo. La primera fase está orientada a implementar una versión funcional de la agenda y sistema de reservas, sin incluir pagos digitales por el momento, para facilitar la adopción progresiva por parte del equipo del centro.
